# 🏎️ AutoAllure.DMD Telegram Bot

Многофункциональный Telegram-бот для центра автомобильного детейлинга **AutoAllure**. Бот автоматизирует процесс взаимодействия с клиентами: от расчета стоимости услуг до ведения базы данных в Google Таблицах.

---

## 🌟 Основные возможности

### 👤 Для пользователей
- **Расчет стоимости услуг**: Удобный выбор марки и модели автомобиля. Бот автоматически определяет ценовой класс авто и выводит актуальный прайс.
- **Портфолио (Галерея)**: Прямая ссылка на облачное хранилище с выполненными работами и отзывами.
- **Оформление заявки**: Быстрая отправка заявки мастеру прямо через интерфейс бота.
- **Обратная связь**: Возможность отправить дополнительное сообщение мастеру после оформления заявки.

### 🛠 Для администраторов
- **Управление базой клиентов**: Автоматическая синхронизация с **Google Sheets** и локальной **SQLite** базой данных.
- **Сегментированная рассылка**: Возможность отправлять посты по разным категориям клиентов (общая база, потенциальные, постоянные).
- **Статистика посещаемости**: Просмотр активности пользователей за текущий день в удобном табличном формате.
- **Прямая переписка**: Отправка сообщений конкретному клиенту по ID чата через бота.
- **Управление статусом**: Перевод клиентов из базы "потенциальные" в "старые" (постоянные) одной командой.
- **Автоматизация**: Ежедневная очистка временного кэша пользователей (Cron на 00:00).

## 💻 Стек технологий

- **Язык**: [Python 3.11+](https://www.python.org/)
- **Фреймворк**: [aiogram 3.x](https://docs.aiogram.dev/en/latest/) (асинхронный Bot API)
- **Базы данных**: 
  - [aiosqlite](https://github.com/omnilib/aiosqlite) (локальное хранилище данных пользователей)
  - [Google Sheets API (gspread)](https://docs.gspread.org/) (для бизнес-аналитики и учета)
- **Логирование**: [Loguru](https://github.com/Delgan/loguru)
- **Планировщик задач**: [APScheduler](https://apscheduler.readthedocs.io/)
- **Менеджер пакетов/сборка**: [uv](https://docs.astral.sh/uv/) + Docker

## 🚀 Быстрый старт

### Требования
1. Python 3.11+ или Docker.
2. Ключевой файл Google Service Account (`base_key.json`) для работы с таблицами.
3. Токен бота от [@BotFather](https://t.me/BotFather).

### Установка (локально)

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-repo/autoallure.dmd.git
   ```

2. **Настройте зависимости** (рекомендуется использовать `uv`):
   ```bash
   uv sync
   ```

3. **Секреты и конфигурация**:
   - Создайте файл `passwords.py` (или отредактируйте имеющийся):
     ```python
     autoallure = 'ВАШ_ТОКЕН_БОТА'
     igor = 12345678  # ID первого администратора
     kostya = 87654321 # ID второго администратора
     loggs_acc = -100123456789 # ID чата для логов (опционально)
     ```
   - Разместите `base_key.json` в корне проекта.

4. **Запуск**:
   ```bash
   uv run python main.py
   ```

### Развертывание через Docker

```bash
docker build -t autoallure-bot .
docker run -d --name autoallure-bot autoallure-bot
```

## 📁 Структура проекта

- `main.py` — Точка входа, регистрация хендлеров и запуск бота.
- `handlers.py` — Логика обработки сообщений и команд.
- `functions.py` — Работа с Google Sheets и бизнес-логика администратора.
- `database.py` — Асинхронная работа с SQLite.
- `keyboards.py` — Описание всех Inline и Reply кнопок.
- `FSM.py` — Состояния (Finite State Machine) для диалогов.
- `price.json` — Структурированные данные о марках, моделях и их классах.
- `1_class.png` ... `4_class.png` — Визуализация прайсов для разных классов авто.
